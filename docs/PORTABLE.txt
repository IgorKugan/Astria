ASTRIA PORTABLE / PORTATIL - WINDOWS X64

ENGLISH
Extract the entire ZIP and open Astria.exe. No installer or Node.js is required.
Keep portable.flag and all supporting files beside the executable.
Use a short writable path such as D:\Astria.

LANGUAGE: Menu > Language > English / Portugues (Brasil). Your choice is saved.

MANUAL UPDATE
1. Close Astria and back up your current folder.
2. Extract the new ZIP elsewhere.
3. Copy all files and folders INSIDE Astria-Portable-x.y.z into your existing folder.
4. Replace program files. KEEP YOUR EXISTING Save folder.
The release ZIP contains no Save folder or personal account data.
Astria.exe must be beside Save, not in another nested version folder.

DATA
Save\Profile: settings and separate browser account profiles.
Save\Games: saves and files downloaded/exported from games.
Game HTTP caches stay inside each account's Profile folder.
Old Save\SharedAssets folders are preserved but no longer used.
Save\Backups: configuration exports and previous programs from updates.
Save\Updates: verified update staging and local update logs.
Save\Temp, Logs, CrashDumps: temporary and diagnostic files.
Save\LEIA-ME.txt: account names and their profile folders.

MOVE / BACKUP
Close Astria, then copy the ENTIRE folder, including Save and support files.
Do not run two copies against the same Save. Never distribute a populated Save.
Online progress normally stays on the server. Windows-protected cookies may
require another login on a different PC or Windows user. Compatibility varies.
Windows may retain its own execution records outside the app folder.

UPDATER
Menu > Check for updates. Download, then choose Restart and update when ready.
Signed manifests and per-file hashes verify the package. Save is kept. The old
program is backed up and restored if replacement or initial UI startup fails.
The executable is not commercially Windows-signed; SmartScreen or Firewall may
show a prompt. Update package signatures are separate from Windows code signing.

PORTUGUES (BRASIL)
Extraia o ZIP inteiro e abra Astria.exe. Nao precisa de instalador nem Node.js.
Mantenha portable.flag e todos os arquivos de suporte ao lado do executavel.
Menu > Idioma permite escolher English / Portugues (Brasil).

PARA ATUALIZAR COPIANDO
Feche o Astria e faca backup. Extraia o ZIP em outro local. Copie todos os arquivos
e pastas DE DENTRO de Astria-Portable-x.y.z para sua pasta Astria atual.
Substitua os arquivos do programa e MANTENHA SUA PASTA Save.
O ZIP limpo nao inclui Save e nao substitui seus perfis, logins ou saves.
Astria.exe deve ficar ao lado de Save, sem outra subpasta de versao.

Profile guarda perfis das contas; Games guarda arquivos exportados/baixados.
Para transferir, feche o Astria e copie a pasta inteira, incluindo Save.
O progresso online normalmente fica no servidor. Outro PC pode exigir novo login.
Nunca compartilhe seu Save preenchido; distribua o ZIP limpo.
Menu > Verificar atualizacoes baixa e verifica o pacote antes de reiniciar.
O Windows pode manter registros e mostrar avisos de SmartScreen/Firewall.
