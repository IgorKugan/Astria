# Astria 1.9.0 — Choose multiple floating accounts

## English

- **Layout → Floating** now opens an account picker. Select several secondary accounts to float over the main game. Change your choices later through **Layout → Floating accounts…** or an account's context menu.
- Each window keeps its own size, position and pin. Clicking a miniature swaps only that account with the main account. Existing sessions remain loaded.
- Saved single-window settings migrate automatically. Selections and window settings survive restarting, switching workspaces and changing layouts.
- Left-clicking a color dot selects the account. Color customization is available through **right-click → Choose color…**, avoiding accidental wheel popups with a collapsed sidebar.

Update using **Menu → Check for updates**. For manual updates, close Astria and replace program files from the portable ZIP while keeping **Save**.

## Português (Brasil)

- **Layout → Flutuante** agora abre a seleção de contas. Marque várias secundárias para flutuar sobre o jogo principal. Mude a seleção depois em **Layout → Contas flutuantes…** ou no menu do botão direito de uma conta.
- Cada janela mantém seu tamanho, posição e alfinete. Clicar em uma pequena troca apenas aquela conta com a principal. As sessões continuam abertas.
- Os ajustes da janela única anterior são migrados automaticamente. Seleção e ajustes persistem ao reiniciar, trocar de espaço ou mudar de layout.
- O clique esquerdo na bolinha de cor seleciona a conta. A personalização fica em **botão direito → Escolher cor…**, evitando abrir a roda por acidente com a lateral recolhida.

Atualize em **Menu → Verificar atualizações**. Para atualização manual, feche o Astria e substitua os arquivos do programa com o ZIP portátil, preservando **Save**.
