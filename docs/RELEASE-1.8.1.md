# Astria 1.8.1 — Resize and pin the floating window

## English

- Drag the floating window's **bottom-right grip** to make it larger or smaller. The game keeps its proportions and stays inside the main image.
- Use the **− / +** buttons for size adjustments without dragging. The resize grip also supports arrow keys.
- Click the **pin** icon to lock its position and size. Clicking the miniature still swaps accounts; unpin to move or resize again.
- Size, position and pin setting are remembered per workspace. Resizing scales the existing page without reloading the game or changing its virtual viewport.

Update using **Menu → Check for updates**. For manual updates, close Astria and replace program files from the portable ZIP while keeping **Save**.

## Português (Brasil)

- Arraste o **canto inferior direito** da janela flutuante para aumentar ou diminuir. O jogo mantém as proporções e fica dentro da imagem principal.
- Use os botões **− / +** para ajustar sem arrastar. O controle do canto também aceita as setas do teclado.
- Clique no **alfinete** para fixar posição e tamanho. Clicar na pequena continua trocando as contas; desafixe para mover ou redimensionar novamente.
- Tamanho, posição e estado fixado são lembrados por espaço. Redimensionar ajusta a escala da página aberta, sem recarregar o jogo nem mudar sua resolução virtual.

Atualize em **Menu → Verificar atualizações**. Para atualização manual, feche o Astria e substitua os arquivos do programa com o ZIP portátil, preservando **Save**.
